# Citing Embodify

If Embodify helps your research, please cite it:

```bibtex
@software{embodify2026,
  title  = {Embodify: Give Your Agent a Body},
  author = {Yang, Yida},
  year   = {2026},
  url    = {https://github.com/YidaYang/embodify}
}
```

When the Embodify paper is published, its citation will be added here.

## Reporting experiments

To make results reproducible, report:

- the Embodify version, the backend and the simulator source revision;
- the task, seed or initial state, and whether `--lock-task` was set;
- the episode budget and per-call step limit, including any change from the backend default;
- the agent host and model;
- whether the agent had experience or robot-profile files from earlier runs.

Apache-2.0 allows reuse without citation; citing Embodify is a scholarly
courtesy, not a license condition.
